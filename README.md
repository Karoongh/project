# Forex Project

A structured prompt and research framework for creating English-language Forex content for X/Twitter, Instagram, YouTube and related platforms.

## System architecture

1. Research Intelligence
2. Post Brief & Trade Configuration
3. Financial Reality & Trade Validation
4. Visual World & Character Continuity
5. Image Prompt Engine
6. Caption & Copywriting Engine
7. Persona / Brand Identity
8. Orchestrator / QA

## Core realism rules

- English-language output unless explicitly requested otherwise.
- Real market data must be distinguished from illustrative/synthetic data.
- If a real trade is represented, instrument, timeframe, date/session, candles, prices, entry, stop-loss and take-profit must remain internally consistent.
- Multiple devices showing the same chart must use the same underlying candle sequence and prices; only crop, zoom or viewport may differ.
- Recurring people must preserve identity. Clothing can change.
- Recurring environments must preserve architecture, dimensions, furniture and object scale. Camera position can change.
- Exterior light should broadly match the represented date/time/session.
- Every image should be a new composition while preserving continuity.
- Never fabricate credentials, employment history, trading results, earnings, regulatory status or other authority signals as facts.
