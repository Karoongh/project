# 02 — Forex Post Brief & Trade Configuration

Use this prompt before generating any individual post.

## Required user inputs

### Content
- Main topic
- Post objective
- Target audience
- Platform
- Format
- Desired CTA

### Market
- Instrument/currency pair
- Timeframe
- Market date/time
- Trading session
- Real historical/current data or illustrative scenario

### Trade
- Direction: long/buy or short/sell
- Trade style: scalping, intraday, day trading, swing, position, long-term, news, breakout, mean reversion, etc.
- Entry
- Stop-loss
- Take-profit
- Desired profit
- Account balance
- Risk percentage
- Lot size, if known

If lot size is unknown, ask for the inputs required for a calculation. A logically calculated lot size may be suggested, but must be labeled as a calculation/suggestion, not a recommendation.

### Visual world
- Person present? yes/no/partial
- Apartment/location
- Camera/location requested by the user
- Time of day
- Weather
- General mood

When a World Bible already exists, the user should only need to specify the desired location and camera.

## Trade-type consistency
The selected trading style must be visible in both image and caption. Scalping should look and read like a short-horizon setup; intraday like a same-day setup; swing like a wider, longer setup; long-term like a higher-timeframe and broader context.

Do not visually present a long-term position as a rapid scalp or vice versa.

## Realism rule
If the post claims to show a real trade, validate the trade details before generation. If illustrative, clearly mark it as illustrative/hypothetical where appropriate.

## Final brief
Summarize all supplied inputs and identify missing or contradictory fields.
